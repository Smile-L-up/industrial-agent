# 专题气象服务-元宵节产品

## 一、规则判定

### 1.1 天气趋势分析判定

- **IF 阴天+雨天≥4天：** "预计元宵节前后我市多阴雨天气，其中[x]～[y]日全市有[降水强度]。"
- **IF 晴天+多云≥4天：** "预计元宵节前后我市以晴到多云天气为主，总体适宜开展户外庆祝活动。"
- **IF 天气转变明显：** "预计元宵节前期[x天气]，后期[y天气]，[具体日期]为天气转折点。"

**元宵节当天必须单独强调：** "其中，[月][日]（元宵节），[天气现象]，气温[x]～[y]℃，[风向风力]。"

**附加判定：**

- **IF 沿海风力≥6级：** "受冷空气影响，[日期]沿海部分乡镇有7～9级[风向]阵风。"
- **IF 有强降水：** "[日期]全市有中到大雨，局部乡镇有暴雨。"
- **IF 有雾或低能见度：** "[日期]早晨我市部分乡镇有雾，能见度较低，对交通出行有不利影响。"

### 1.2 关注与建议判定

**第一条（元宵节当天天气）：**

- **IF 有降水：** "元宵节当天有[降水]，将导致道路湿滑、能见度降低，对元宵赏灯、民俗活动及公众出行带来不利影响。"
- **IF 无降水但有大风：** "元宵节当天风力较大，可能影响户外灯展效果和安全，建议赏灯人员做好防风措施。"
- **IF 天气晴好：** "元宵节当天天气条件良好，适宜开展各类户外赏灯和民俗活动，建议公众合理安排出行时间，错峰观赏。"

**第二条（其他关注）：**

- **IF 有降水+大风：** "受降水和大风共同影响，道路湿滑且能见度降低，交通安全风险增大，建议公众减少不必要出行，必须出行时注意安全。"
- **IF 气温变化大：** "元宵节期间气温起伏较大，建议公众根据温度变化适时增减衣物，防止感冒。"
- **IF 有大风：** "提醒赏灯人员做好防风保暖措施，并注意安全。"

### 3.2 模板填写说明

#### 天气趋势分析

- 根据未来一周天气统计选择对应判定描述
- 元宵节当天必须单独一段强调
- 有沿海大风、强降水、雾等需追加描述

#### 逐日天气预报

- **预报时效：** 前日20时～当日20时
- **预报时长：** 未来一周（7天）
- **预报要素：** 天气现象、市区气温、市区风
- **元宵节标注：** 元宵节当天需加"（元宵节）"标注

#### 关注与建议

- 第一条必须针对元宵节当天天气
- 第二条针对其他需关注的天气情况
- 根据实际天气选择1-2条建议
