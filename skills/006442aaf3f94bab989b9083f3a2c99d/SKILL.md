# 专题气象服务-中考产品

## 一、规则判定

### 1.1 中考天气趋势分析判定（前7天到考前3天）

**总体特征判定：**

- **IF 多云/晴天≥5天：** "预计中考期间我市以多云/晴好天气为主，总体有利于中考顺利进行。"
- **IF 雨天≥3天：** "预计中考期间我市多阵雨或雷阵雨天气，其中[x]日和[x]日降水较为明显。"
- **IF 高温天气(≥35℃)≥2天：** "预计中考期间气温较高，[x]日至[x]日最高气温可达32～35℃，需注意防暑降温。"
- **IF 天气转变明显：** "预计中考前期[x天气]，中考期间[x天气]，[具体日期]为天气转折点。"

### 1.2 关注与建议判定

- **IF 有雷电：** "（1）关注雷雨天气对考生出行和交通安全的影响。（2）关注雷电活动对考场电子设备带来的不利影响，建议提前做好应急防范准备。"
- **IF 有高温：** "XX～XX日白天气温较高，体感闷热，请注意做好防暑降温工作。"
- **IF 有降水：** "预计XX天我市多阵雨或雷阵雨天气，请关注降雨天气对考生出行和交通安全的影响。"

### 1.3 区域描述判定（精细化预报必须区分三类区域）

1. **沿海及德化：** 作为一个组。
2. **安溪、永春、南安：** 作为部分高温区。
3. **市区（丰泽、鲤城、洛江等）。**

示例："沿海及德化最高气温31～33℃，安溪、永春、南安部分乡镇达33～35℃。"

**注意：** 有明显降水天气要重点提及"降雨时局地伴有雷暴、短时强降水等强对流天气"。

### 1.4 考点雷电活动判定

**近1小时回顾：**

- **IF 有雷电：** 统计出现雷电附近考点。
- **IF 只有降水没有雷电：** 统计出现降水的考点，加"但无雷电活动。"

**14～17时预报：** 根据雷电预报预测14-17时可能出现雷电的考点。

### 1.5 突发天气预报判定（视情况发布）

针对突发天气变化发布，示例："预计未来2小时（13:35～15:35）安溪、南安、永春、洛江、德化局部(镇、街道)有阵雨或雷阵雨，安溪局部伴有弱雷电活动。目前雷电活动趋于减弱，对英语听力考试的影响较小。"

## 二、数据源获取方法

| 数据源 | 数据内容 | 获取方式 |
|--------|---------|---------|
| 天气预报数据 | 未来十天逐日天气预报、气温 | 通过气象预报业务系统获取 |
| 各县（市、区）逐日预报数据 | 各区县逐日天气、气温（08时～次日08时） | 通过气象预报业务系统获取精细化预报 |
| 各县（市、区）逐时预报数据 | 各区县逐小时天气、气温 | 通过气象预报业务系统获取逐时精细化预报 |
| 雷电监测/预报数据 | 雷电活动实况及预报 | 通过雷电监测系统和雷电预报系统获取 |
| 考点信息数据 | 各区县考点名称、位置 | 由教育部门提供考点清单 |

```
### 3.7 模板填写说明

#### 发布时间节点

| 阶段 | 发布时间 | 内容 |
|------|---------|------|
| 天气趋势分析 | 考前7天到考前3天 | 未来十天逐日天气预报 |
| 期间天气预报 | 考前3天到考前1天 | 天气趋势+关注建议+各县逐日预报 |
| 精细化预报（第一天） | 考试日当天06:00前 | 最新实况+逐时预报 |
| 考点雷电预报 | 考试第二天中午前 | 雷电回顾+14-17时预报 |
| 精细化预报（第二三天） | 考试第二三天 | 分时段+分区县精细预报 |
| 突发天气预报 | 视情况发布 | 未来2小时雷电影响考点 |

#### 区域描述规则

精细化预报中必须区分三类区域：
1. 沿海及德化（一个组）
2. 安溪、永春、南安（高温区）
3. 市区（丰泽、鲤城、洛江等）

#### 中考时段说明

中考时段与高考不同，注意时间安排：
- 上午考前：7:00～8:30
- 上午考中：8:30～10:00
- 间歇：10:00～10:45
- 下午考中：10:45～11:45
- 下午考后：11:45～13:00
- 下午考前：13:00～15:00

```
