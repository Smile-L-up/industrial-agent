# 专题气象服务-两会产品

## 一、规则判定

### 1.1 北京天气判定

- **IF 北京预报有降水(雨/雪)：** 突出预报降水时段、强度及对出行的影响。
- **IF 北京昼夜温差>8℃：** 强调温差变化对人体舒适度的影响。
- **IF 北京气温<0℃：** 重点提示昼夜温差大。

### 1.2 泉州天气判定

- **IF 本地与北京温差>8℃：** 必须强调"南北温差大"这一特点。
- **IF 本地有明显降水：** 需说明对当地代表出发前准备的影响。
- **IF 本地天气稳定：** 重点描述天气对参会人员出发时的适宜度。

### 1.3 关注与建议判定

**（1）着装防护建议：**

- **IF 南北温差大：** "着装防护：泉州温暖、北京干冷，南北温差大，建议采用洋葱式穿衣，外穿防风厚外套，便于室内外增减；北京昼夜温差大，注意防寒保暖，谨防感冒。"
- **IF 北京有持续低温：** "北京气温偏低，建议携带防寒物品，室内温度较高，可采用多层穿搭方式，方便随时调整。"

**（2）交通出行建议：**

- **IF 北京有降水/雪：** "交通出行：预计[日期]北京有[雨雪]天气过程，道路湿滑，对[早/晚]高峰交通有明显影响，请提前做好防范，合理安排出行。"
- **IF 北京有大风：** "北京有大风天气，户外活动时请注意防风，机场、高铁站等交通枢纽可能受大风影响出现延误，建议预留充足时间。"
- **IF 两地天气差异大：** "从泉州前往北京，将经历较大温差，请提前调整身体状态，避免温差过大引起不适。"

## 二、数据源获取方法

| 数据源 | 数据内容 | 获取方式 |
|--------|---------|---------|
| 泉州天气预报数据 | 泉州市区三天天气预报、气温 | 通过气象预报业务系统获取 |
| 北京天气预报数据 | 北京城区十天天气预报、气温、降水、风力 | 通过国家气象局预报数据接口获取北京天气预报 |
| 温差计算数据 | 泉州与北京温差对比 | 基于两地预报气温数据计算温差 |

### 3.2 模板填写说明

#### 天气趋势分析

**北京部分：**

- 有降水时：明确降水时段（如"3月5日夜间至6日上午"）、强度（小雪/中雪/大雪）
- 温差大时：标注昼夜温差具体数值（如"昼夜温差达12℃"）
- 低温时：强调最低气温和体感温度

**泉州部分：**

- 必须与北京进行对比
- 温差>8℃时必须使用"南北温差大"表述
- 有降水时说明对代表出发的影响

#### 天气预报

- **泉州预报：** 3天，包含天气现象和气温范围
- **北京预报：** 10天，包含天气现象和气温范围
- **气温格式：** [最低]～[最高]℃

#### 关注与建议

**着装防护：**

- 优先级1：南北温差大（温差>8℃）
- 优先级2：北京持续低温（气温<0℃）

**交通出行：**

- 优先级1：北京有降水/雪
- 优先级2：北京有大风
- 优先级3：两地天气差异大
